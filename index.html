Course project · COMP-108

Volt Tracker

A C++ terminal app for tracking and analyzing monthly electricity use, with a UI concept for a future version.

  • C++
  • Input validation
  • File I/O
  • UI concept
Read the case study

The idea

Many people don't know how much electricity they use each month, or which months spike. Volt Tracker makes it easy to enter monthly readings and analyze them.

What I built

  • Data storage: an array that holds 12 months of readings.
  • Calculations: separate functions for the total, the average, and the highest and lowest months.
  • Menu: a loop that repeats until the user chooses to exit.
  • Input validation: rejects letters and negative numbers, and asks again instead of crashing.
  • Extras: readings sorted from lowest to highest, and an analysis of months above a user-defined limit.
  • Report: saves the results to report.txt.
  • Documentation: a README with the idea, how to run it, and a list of functions.

What I learned

  • Breaking a program into small functions, each with one job.
  • Working with arrays and loops.
  • Handling invalid input in C++ with cin.clear and cin.ignore.
  • Writing files and organizing a project on GitHub.

The UI concept

An early design for a future version: a dashboard, a readings screen, and a threshold analysis. It's a concept and isn't connected to the code yet.
